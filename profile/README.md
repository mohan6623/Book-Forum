## 🚀 Projects

### 📚 BookForum — Social Book Discovery Platform
> A full-stack, community-driven platform for discovering, rating, and discussing books.

| Layer | Technology |
|-------|-----------|
| **Frontend** | React 18, TypeScript, Vite, Tailwind CSS, Shadcn UI |
| **State & Data** | TanStack Query, React Router DOM |
| **Forms & Validation** | React Hook Form, Zod |
| **Backend** | Spring Boot, Spring Security, JWT, OAuth2 |
| **Database** | PostgreSQL (via Supabase) |
| **Deployment** | Vercel (Frontend) |

**Key Features:**
- 🔐 Authentication via Email/Password, Google & GitHub OAuth2
- 📖 Book catalog with search, filters, and pagination
- ⭐ Ratings (1–5 stars), comments, and user profiles
- 🛡️ Admin dashboard — add/edit/delete books, image uploads via Cloudinary
- 🌙 Dark mode, toast notifications, and responsive design

🔗 **[View Repository](https://github.com/mohan6623/Book-Forum)**
